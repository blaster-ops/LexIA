Fuente de conocimiento

Repositorio vectorial de documentos jurídicos indexados para consulta semántica.

247
Documentos indexados
Estado del repositorio vectorial ChromaDB · Activo

La base vectorial ChromaDB se encuentra operativa. Los documentos PDF ingresados son procesados mediante embeddings y almacenados para consulta semántica de alta precisión. Última sincronización: hace 3 minutos.

Para agregar nuevos documentos al corpus jurídico, utilice el botón "Ingresar PDF" en la parte superior de esta sección.

Formato y requisitos de documentos
  • Formato aceptado: PDF (texto seleccionable, no escaneados sin OCR).
  • Tamaño máximo por documento: 50 MB.
  • El tiempo de indexación varía según la longitud del documento.
  • Los documentos indexados son accesibles para todos los usuarios del sistema.
